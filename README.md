# Minesweeper Prototype

A small Minesweeper prototype built with C# and WPF.

The main goal of this project is to experiment with game logic, MVVM, and a simple desktop UI using .NET.

## Features

- 9x9 board
- Random mine placement
- Adjacent mine calculation
- Reveal logic
- Flagging
- Win and lose conditions
- 120 second countdown timer
- Reset button
- Simple retro-inspired UI

## Tech

- .NET 10
- C#
- WPF
- CommunityToolkit.Mvvm

## Project Structure

- `MinesweeperPrototype.Core` - board and game rules
- `MinesweeperPrototype.Application` - game flow and services
- `MinesweeperPrototype.Wpf` - UI and view models

This is just a learning prototype and may change as I experiment with new ideas.
